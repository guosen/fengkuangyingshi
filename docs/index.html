Tier1 快速步骤

  • Fork 本仓库，Settings → Pages → Source 选 GitHub Actions
  • Actions 运行 Sync LibreTV sources，确认本页可打开
  • 部署 LibreTV 到 Vercel，设置 PASSWORD 与 DEFAULT_SUBSCRIPTIONS（见仓库 README）
  • 手机浏览器打开 LibreTV 地址 → 添加到主屏幕

数据文件

  • sources.json — LibreTV 订阅
  • manifest.json — 生成时间与源明细
私人使用请设置访问密码；公开传播需自行评估版权与合规风险。迁移 VPS 见仓库 docs/DEPLOY-VPS.md。
